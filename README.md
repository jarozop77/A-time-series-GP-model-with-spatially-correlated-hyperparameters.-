# A Time-Series Model for Areal Data Using Area-Specific Gaussian Processes with Spatially Correlated Hyperparameters

This repository contains the R code accompanying the manuscript

> **A Time-Series Model for Areal Data Using Area-Specific Gaussian Processes with Spatially Correlated Hyperparameters**

The repository provides two independent implementations of the proposed Bayesian spatio-temporal model:

1. **A tailor-made MCMC algorithm**, specifically developed for the proposed hierarchical model.
2. **A Stan implementation**, providing a reference implementation using Hamiltonian Monte Carlo.

Both implementations reproduce the complete analysis workflow presented in the manuscript, including model fitting, convergence assessment, posterior predictive inference, and model diagnostics.

To illustrate the methodology, the repository includes a **simulated dataset** inspired by monthly malaria incidence in Mozambique. The example dataset consists of observations from **16 districts** over **60 monthly time points**, covering the period **January 2017 to December 2021**.

---

# Repository structure

## `data/`

This folder contains all data required to reproduce the example analysis.

### `simulated_data.RDS`

A simulated dataset used to demonstrate the proposed modeling framework.

### `district_boundaries.RDS`

Spatial polygon data for the 16 districts included in the simulated example.

### `input_files_init_values/`

This folder contains initialization files generated by running

```text
District_specific_models.R
```

Specifically, it includes:

- maximum likelihood estimates of the district-specific covariance parameters
  - $\sigma_i^2$
  - $\phi_i$
  - $\nu_i^2$
- estimated covariance matrices of these parameter estimates.

These quantities are used to construct informative initial values for the tailor-made MCMC sampler.

---

## `stan_implementation/`

This folder contains the Stan implementation of the proposed model.

### Main files

- **`Execution.R`**

  Fits the hierarchical spatio-temporal model using Stan. The script automatically sources `Preprocessing.R`, which prepares the data and model inputs.

- **`posterior_analysis.R`**

  Loads the fitted model, performs convergence diagnostics, computes posterior predictive summaries, and generates the figures and summary statistics used to assess model performance.

### Running the Stan implementation

Execute the scripts in the following order:

1. `Execution.R`
2. `posterior_analysis.R`

---

## `tailor_made_algorithm/`

This folder contains the implementation of the tailor-made MCMC algorithm developed specifically for the proposed model.

### Main files

- **`District_specific_models.R`**

  Fits independent Gaussian process models to each district to obtain initial values for the hierarchical sampler.

- **`Execution.R`**

  Runs the tailor-made MCMC algorithm for the hierarchical spatio-temporal model.

- **`posterior_analysis.R`**

  Performs convergence diagnostics, computes posterior predictive summaries, and produces the main diagnostic plots.

Additional supporting files include:

- **`Inputs_sampler.R`**, which constructs the inputs required by the MCMC sampler.
- **`sampler.R`**, which implements the tailor-made MCMC algorithm.

### Running the tailor-made implementation

Execute the scripts in the following order:

1. `District_specific_models.R`
2. `Execution.R`
3. `posterior_analysis.R`

# Applying the model to other datasets

The framework is designed to be easily adapted to other areal time-series datasets.

In most applications, only a small number of modifications are required, including:

- replacing the input dataset;
- updating the spatial and temporal indexing variables;
- modifying the MCMC settings, if desired.

These changes can typically be made directly within `Execution.R` and `posterior_analysis.R`.
